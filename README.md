# Low-Level Design (LLD) Learning Journey

This repository documents my journey of learning **Low-Level Design (LLD)** using **C++**.

I am following the **Coder Army LLD playlist by Aditya Ranjan Tandon**. After learning each concept, I implement it myself and push the code here for revision, practice, and progress tracking.

> This is a learning repository. The implementations may evolve as I understand better design approaches and discover new patterns.

## Goals

- Build a strong foundation in object-oriented design
- Learn how to convert real-world requirements into classes and objects
- Write clean, modular, maintainable, and extensible code
- Understand and apply SOLID principles
- Study commonly used design patterns
- Improve problem-solving for LLD interviews

## What I Am Learning

- Object-Oriented Programming fundamentals
- Classes, objects, constructors, and access modifiers
- Abstraction, encapsulation, inheritance, and polymorphism
- Association, aggregation, and composition
- UML and class relationships
- SOLID design principles
- Design patterns
- Requirement analysis
- Real-world LLD problems

## How I Approach Each Problem

1. Understand the requirements and expected behaviour.
2. Identify the main entities and their responsibilities.
3. Define relationships between the classes.
4. Apply suitable OOP and SOLID principles.
5. Implement the design in C++.
6. Review the code and improve it when I learn a better approach.

## Running the Code

Clone the repository:

```bash
git clone <your-repository-url>
cd <repository-folder-name>
```

Compile and run a C++ file:

```bash
g++ -std=c++17 filename.cpp -o app
./app
```

On Windows PowerShell, run the compiled program with:

```powershell
.\app.exe
```
